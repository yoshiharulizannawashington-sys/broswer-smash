# broswer-smash

High-quality platform fighter demo — procedural characters + CC0/permissive assets (no copyrighted characters included).

## Run locally

1) Install a static server (optional):
   - npm i -g http-server
   - http-server public -c-1
   - open http://localhost:8080

2) Or use Python:
   - cd public
   - python -m http.server 8080
   - open http://localhost:8080

This repo contains a polished Three.js demo with PBR-like lighting, postprocessing (bloom, SSAO, outline), input buffering, hitboxes, knockback and cinematic camera effects.
