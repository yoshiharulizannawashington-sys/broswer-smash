# Rig fixture (test asset, not a character)

`rig-test.glb` is a **synthetic test fixture**, generated by `scripts/make-rig-fixture.mjs` from
original geometry authored in this repository. It exists so the animation pipeline can be tested
against a real skinned glTF.

- 11 joints named the Mixamo way (`mixamorig:Hips`, `mixamorig:LeftArm`, `mixamorig:LeftLeg`, …),
- one skinned mesh weighted to the hips,
- two clips (`Idle`, `Punch`),
- about 4 KiB.

It is **not** registered in `characters/manifest.json`, so no fighter can select it and the game
never loads it. Nothing here is downloaded, and no third-party licence applies.

Regenerate and verify:

```sh
npm run make:rig-fixture     # writes rig-test.glb
npm run test:animation       # loads it through GLTFLoader and asserts the pipeline
```
